# Dependency Review

## Purpose

Review project dependency declarations and verify dependency management files remain consistent.

## Review Criteria

- Verify dependency manifests exist for managed projects.
- Verify Node projects have package lockfiles.
- Identify dependency manifests without expected lockfiles.
- Identify unmanaged dependency definitions where applicable.

## Evidence

Completed reviews should reference:

- dependency manifests checked
- findings
- follow-up backlog items

## Related Areas

- Node dependencies
- Python dependencies
- Build tooling
- Project configuration
