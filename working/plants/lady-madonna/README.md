# Lady Madonna Working Profile

This directory is the canonical working source for Lady Madonna's Orchid Rescue
profile.

## Source Material

- `sources/Lady-Madonna.pdf` preserves the exported care conversation.
- `photos/` preserves the supplied photographs and XMP sidecars.
- `facts.yaml` owns structured plant metadata.
- `history.md` owns the verified chronology.
- `story.md` contains the public narrative.
- `inventory.md` records the latest documented physical state.
- `photo-metadata.md` records photo provenance and publication choices.

## Evidence Notes

- The first documented assessment is dated 2026-01-05.
- The exact acquisition date is unknown. I recall a likely $5 Lowe's clearance
  purchase in late 2025, so those details remain explicitly uncertain.
- Embedded image dates, XMP sidecars, conversation timestamps, and the PDF
  sequence establish the documented timeline.
- `Lady_Madonna - 15.xmp` and `Lady_Madonna - 21.xmp` are preserved even though
  their matching numbered photographs were not present in the supplied set.
