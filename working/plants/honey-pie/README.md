# Honey Pie Working Profile

This directory is the canonical working source for Honey Pie's Orchid Rescue
profile.

## Source Material

- `sources/Plants-Honey-Pie.pdf` preserves the exported care conversation.
- `photos/` preserves the supplied photographs and XMP sidecars.
- `facts.yaml` owns structured plant metadata.
- `history.md` owns the verified chronology.
- `story.md` contains the public narrative.
- `inventory.md` records the latest documented physical state.
- `photo-metadata.md` records photo provenance and publication choices.

## Evidence Notes

- The PDF begins on 2026-06-14, when the orchid was named.
- The PDF's `6/28/06` label is treated as a typo for 2026-06-28 because the
  surrounding weekly sequence and the matching XMP dates agree.
- The 14 numbered photographs map to the 14 matching XMP sidecars.
- Public photo choices favor the clearest overall, bloom, leaf, and root views
  while keeping redundant frames private.
