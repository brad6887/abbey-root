# Rocky Raccoon Plant Publication

## Summary

Rocky Raccoon was sitting on the Lowe's clearance rack looking like he'd had a rough week.

He also became exactly the real-world test the new plant onboarding command needed.

The first run exposed two things the original regression fixtures had missed: the command copied the photograph but not its XMP sidecar, and validation was satisfied by files that still contained untouched template instructions. Both issues were fixed before Rocky's workspace was recreated.

## Accomplishments

- Corrected Rocky's misspelled XMP description before import.
- Renamed the original photo and sidecar through the Abbey plant workflow.
- Created Rocky's canonical workspace with `abbey plant new`.
- Preserved the original photograph and adjacent XMP metadata.
- Recorded the initial rescue story, history, inventory, facts, and photo provenance.
- Published sanitized public images without private metadata.
- Generated Rocky's Orchid Rescue page and built the complete site successfully.
- Validated the merged plant suite with 104 passing tests.

## Lessons Learned

The best test of an onboarding workflow is onboarding something real.

Rocky's first run showed that “the files exist” is not the same as “the content is finished,” and that preserving a photograph includes preserving the metadata beside it.

The remaining unknown species is not missing work. It is an honest record of what the tag did not say.
